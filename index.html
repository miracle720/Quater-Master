Auto-send every day at 12:00 AM
Posts the previous day's outbound summary (orders, SKUs, customers that were moved to dispatch — pending batches are left out) to Slack — requires this app to be open in a browser tab at midnight. For guaranteed delivery even when nobody has the app open, use the Cloud Function below instead.

Guaranteed midnight delivery (recommended)

The toggle above only fires if someone's browser has this app open at midnight. For a summary that sends every single night — even if the app is closed — deploy this as a Firebase Cloud Function instead. It runs on Firebase's servers on a fixed schedule.

  1. Download the function file below
  2. Paste your Slack webhook URL and warehouse name(s) into it where marked
  3. In your Firebase project folder, run firebase init functions (Node 18+), then replace index.js with the downloaded file
  4. Run firebase deploy --only functions
  5. It will run automatically every day at 12:00 AM (adjust the time zone in the file if needed)
